# Scroll-Driven Hero Section Animation

## Overview
This is a React-based scroll-driven hero animation inspired by the provided reference. It creates an immersive, premium dark-themed landing page experience by pinning the hero section and transforming a custom visual based on the user's scroll progress.

## Features
- Premium responsive hero section
- Letter-spaced headline
- Animated statistics
- GSAP entrance animations
- GSAP ScrollTrigger
- Scroll-driven car/visual animation
- Scrub-based animation
- Pinned hero section
- Responsive desktop and mobile layout
- Performance-focused transform animations

## Tech Stack
- React
- Vite
- JavaScript
- Tailwind CSS
- GSAP
- GSAP ScrollTrigger

## Run Locally

```bash
npm install
npm run dev
```
